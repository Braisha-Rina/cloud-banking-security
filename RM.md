# Privacy-Preserving Cloud Banking Security Platform

A cybersecurity project focused on cloud security and privacy-preserving
processing of sensitive banking data.

Problem:

Banks store and process highly sensitive financial data in cloud environments. A cloud provider cannot be fully trusted with plaintext sensitive data, and security weaknesses or unauthorized access may lead to data exposure or leakage.

Goal:

To design and implement a secure cloud-based banking system that protects sensitive financial data, minimizes the trust placed in the cloud provider, and reduces the risk of unauthorized data exposure.

Main Idea:

The project combines cloud security mechanisms with privacy-preserving data processing to allow useful banking operations while reducing the exposure of sensitive data.

## Users

### Customer

* Log in to the banking system
* View personal account information
* Perform transactions

### Bank Analyst

* Access authorized banking analytics
* View approved analytics results
* Analyze transaction-related information

### Security Administrator

* Manage security settings
* Monitor security-related events
* Manage access permissions
